### Hi, I'm Liem 👋

I'm a flat-rate automotive technician in California, and a self-taught software developer. I build tools for the work I know from the inside.

### 🔧 What I'm building

**[Flat Rate Ledger](https://github.com/fjeX/flatrateledger)**: a pay record for flat-rate technicians. Log every repair order from your phone, watch your pay period in real time, and catch a shorted paycheck before payday. It's live, technicians use it, and I designed, built and run it on my own.

[Read the case study](https://github.com/fjeX/flatrateledger) · [Live site](https://flatrateledger.com) · [Try the demo](https://demo.flatrateledger.com)

- **Shipping:** Vercel, GitHub Actions, Playwright, Vitest
